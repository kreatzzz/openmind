# Openmind contributor instructions

This repository currently contains plans only. Do not interpret proposed milestones as authorization to implement them. Follow the user's current task scope.

Read `docs/decisions.md` and the relevant architecture documents before changing a plan. Read `DESIGN.md` before creating or changing UI. Keep recommendations distinct from confirmed decisions and working software.

Use synthetic personal histories in examples and tests. Never commit real conversations, vaults, credentials, or model weights. Do not add content telemetry.

When implementation begins, use the repository's configured package manager. The proposed default is Bun for frontend tooling and Cargo for Rust. Do not start development servers unless requested. Follow the user's skill requirements, including `vercel-react-best-practices` for React work.

Do not describe hidden memory as inaccessible to the device owner, or describe AI support as established clinical treatment. Preserve evidence, correction, deletion, and explicit remote-provider consent in architectural changes.
